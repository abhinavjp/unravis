## Findings

Severity: H blocks or harms a task, M friction or inconsistency, L polish.

1. **M (fixed, UX-11)** The "Skip to main content" link pointed at `#main-content`, which did not exist (axe `skip-link` and `region` on every screen). It worked only through its click handler. `<main>` now has `id="main-content"` and `tabindex="-1"`. Shared fix, every screen; axe now 0 on the reached screens except the update bar (UX-15).
2. **M (fixed, UX-12)** Two fonts for one product. The Start screen, the create-case wizard, the master-key setup and unlock cards and the re-wrap notice set the whole screen in the monospace face; the case home, analysis page and Blackbox wizard use the body face. The first screens a person sees looked like a different app, and long mono paragraphs wrap sooner and read slower. The UI direction spec says "system stack" with mono for figures; mono is now kept for figures, codes and file names only.
3. **L (not changed, UX-5)** Header: "Demo data" and "Data reference time ..." still run together; left as is because BL-159 closed it (the label exists only in the demo build).
4. **L (fixed)** Erase screen: the title was an `h3` straight after the page `h1` (axe `heading-order`). Now `h2`.
5. **H for the factory, M for users (open, UX-13)** `tools/screens/screens.json` no longer matches the UI for 39 screen variants: the Blackbox wizard's "Next: Where" is now "Next", "Open guided analysis" is now "Open the analysis", the create-case "Import files" button and the "Use this case" Import list are gone, the Blackbox status pop-up has no "Back to the list". CI keeps the screenshot compare non-blocking, so this drift was silent and the user guide pictures for those screens are stale.
6. **M (open, UX-14)** Case home, "SQL Server and MongoDB" card: seven equal buttons, two of them named "Step 7: SQL Server" and "Step 8: MongoDB". The step numbers come from the guided flow and mean nothing on this card; the "Sources" toggle looks like the action buttons beside it.
7. **L (open)** Repeated lead text: the Start screen says "Open a case you already have, enter a case code, or create a new case." and right under it "Pick a saved case, enter a case you were given, or begin a new one."; the "Enter an existing case" card does the same. One of each pair can go.
8. **L (open)** "Restore from a case file" is a link in a case row and a borderless button in the Enter card: same action, two looks.
9. **L (open)** A keyed case with no readable date shows "· Code demokeye" with a leading separator.
10. **L (open, UX-15)** The update bar sits outside every landmark (axe `region`). Wrap it in a `role="region"` with a label, or move it into the header.
11. **L (open)** Case home: the health-check block's section label repeats another landmark's label (axe `landmark-unique`). Sources > Nothing read: one table header cell is empty (axe `empty-table-header`).
