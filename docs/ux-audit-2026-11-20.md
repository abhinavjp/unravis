# UX audit, 2026-11-20

Scope: the web app (analysis page, header panels, Blackbox panel, status, charts, Place a Blackbox wizard), phone width, dark theme, keyboard. Method: the demo build in headless Chromium (1366, 820, 390 wide), axe-core (WCAG 2.2 AA tags) on each screen, a Tab-order walk, and code reading for the add-source copy.

## Findings

Severity: H blocks or harms a task, M friction or inconsistency, L polish.

1. **H (fixed, UX-1)** The Blackbox panel lets Tab leave the dialog. The shared Drawer counted hidden controls (a closed status pop-up) as the last focusable item, so the wrap never fired. 12 of 25 Tab presses landed on the page behind. Fix in `Drawer.svelte` (skip controls that are not on screen). Other drawers were not affected in the demo; they now share the same rule. WCAG 2.4.3, 2.1.2 spirit.
2. **M (open, UX-2)** One action, three names: scanning this computer is "Scan this computer" (Discover), "Scan this PC" (Blackbox panel) and "Find on this PC" (source wizard tile). Adding a recorder is "Place a Blackbox" (panel, wizard), "Add a Blackbox" (Sources hub). Adding data is "Add data", "Add sources", "Add a source", "Add files", "Add more data". Fix: one copy module for the shared verbs, used by every screen. Needs a Windows pass to compare the validation and feedback of the three add-source entry points (wizard, Sources list, add-to-case) before changing behaviour.
3. **M (open, UX-3)** On the Start screen, a failed case list shows a red box and "Try again" next to two live cards that look usable. Without cases, "Enter an existing case" accepts a code that cannot open. Check on Windows; the likely fix is to disable or explain the other cards.
4. **L (open, UX-4)** Blackbox panel: "Add one by folder, share or address" is a bare text link next to two buttons, so it reads as a label. The explanatory paragraph (about 70 words) sits between the actions and the list.
5. **L (open, UX-5)** Header: "Demo data" and "Data reference time ..." run together without a separator at 1366 px.
6. **L (open, UX-6)** Phone: Range, Type and More filters take about 40% of the first screen before any data.
7. **L (open, UX-7)** Sources popover lists "demo / audit" twice under two computers; the row label alone does not tell which is which if the computers were collapsed.

Not found (checked): colour contrast, labels, names, roles, focus visibility in the demo (axe: 0 violations on every reached screen), page-level horizontal scroll at 390 px, Place wizard name validation (shows an inline problem and `aria-invalid`).
