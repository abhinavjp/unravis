## Top 5 by value

1. GO-R2-01 error-count rule lives in the wrong layer and the doc lies about it.
2. GO-R2-02 uintptr held across statements in `buildMenu` (GC safety).
3. GO-R2-03 per-row `json_extract` in the new error count on big IIS cases.
4. GO-R2-04 `State()` size walk on every state read and on open-log-folder.
5. GO-R2-05 nil dereference in uninstall `DescribeChanges`.
