## Verified OK (not defects)

- S1 08:00-12:00 counts match the API: IIS 131 (max 55), SQL 21, audit 8. S2 bucket counts total 40 (4,3,3 repeating).
- Midnight boundary (S5): 23:59 holds 2 and 00:00 holds 2; typed UTC is sent as Z; Local toggle (Asia/Dubai) changes axis, caption and tooltips while the pickers stay UTC and labelled.
- 30-day window gives 6 h buckets and 120 buckets. A 31-day comparison window is refused with a clear message.
- Audit error shading renders correct overlay heights and tooltip lines when `errors` is present (UI-R1-01 is that IIS never sends it).
- Rapid clicking: six clicks on Start tracing send one request (button disabled while loading). Back/forward during a trace gives no console errors. No console errors anywhere in the run.
- Dark theme tokens fine (body 5,8,7; text 238,243,241; axis text 147,163,155). No horizontal overflow at 768 or 375.
- Keyboard: arrow keys reach the first and last slot; Escape hides the tooltip; the overlay has a clear aria-label.
