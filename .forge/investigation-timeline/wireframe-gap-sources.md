# Wireframe gap analysis: SOURCE side (adding data to a case)

Read-only analysis, 2026-11-04. Scope: adding a source or data to a case, the sources list and its states, detect-kind, time zone, retry and remove, the "Add data" entry points, copy. The Investigation Timeline chart itself is covered by `wireframe-gap-triage.md` and `wireframe-match-tracing.md`; this file covers only what those did not.

Trigger: owner said "For IIS logs adding, the wireframe had something different; that is not implemented", "I don't think all of it is implemented", and that the saved Sandbox API Audit DB was not added to the analysis.

## Sources compared

Wireframe side:
- `prototype/tracing-paper-PROTOTYPE.html` (P): `FILE_KINDS`, `READS`, `KIND_TZ`, `detectKind`, `FINDINGS` (about 619-640); `reqPanel('iis')` (742); `wizSources()` with four method tabs (757-775); Mongo and SQL panels (776-795); files section, drag-drop, folder or path, `wizFileAdd` (796-830); review and retries (849-870); case home retries and Files (900-925); `DRAWERS.import` (985-1005); timeline `trParts` sources chips and "Add evidence" (1176-1236).
- `buildout/wireframes/workflow-walkthrough.html` (W): screens w13-w15, w37-w51, w112-w115 (`<section class="shot" id="wN">`, lines 743-948).

App side: `web/src/components/wizard/*`, `web/src/lib/wizardSources*.ts`, `web/src/lib/wizardSubmit*.ts`, `web/src/lib/components/ImportPanel.svelte`, `CaseHome.svelte`, `web/src/components/sources/*`, `ConnectionsDrawer.svelte`, `TracingPaper.svelte` (read only), `internal/importer/iis/*`.

## What is actually implemented well (so it is not rebuilt)

- "This computer" scan with grouped findings, chips Ready / Not checked / Needs an export, Needs administrator, Large, the "Where is it?" path check: `SourceGallery.svelte`, `LocateFolder.svelte` (matches P `wizScan`, `wizLocate`).
- Server-side detection of a file's type and its IIS W3C, HTTPERR and FREB importers (`internal/importer/iis/w3c.go`, `httperr.go`, `freb.go`; auto-detect by content, with "pick the type" when tied or unknown) used by the after-case import drawer `ImportPanel.svelte`: preview counts, rejected reasons, time-zone rule shown, Host select, duplicate status, acknowledgement.
- Case home "needs another try" list: Try again / Add the file again / Remove from list (`CaseHome.svelte` 327-352, 460-478).
- Add data hub: SQL / MongoDB / Blackbox / Files / Another day cards (`AddDataPanel.svelte`, `SourcesHub.svelte`), saved connections page.
- Mongo wizard: saved connection pick, test, per-database classification, audit source registration on create (`MongoClassify.svelte`, `wizardSubmit.ts` 175, 308-318, `wizardSubmitApi.ts` 58).
