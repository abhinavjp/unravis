## Pattern source
`internal/blackbox/mempressure.go` is NOT present in this worktree, so the counter-group pattern was copied from `internal/blackbox/http.go` (BBX-2-01) / `diskcpu.go`, per instruction:
- `init()` → `RegisterGroup("aspnet", true, newASPNETGroup)` — optional=true.
- Factory `newASPNETGroup(d GroupDeps)`: uses `d.Source` when injected (tests); otherwise `NewPDHSource(aspnetPaths)` and returns the error on failure so `BuildGroups` skips it (non-Windows stub returns `errPDHWindowsOnly`; also skips when ASP.NET objects are absent). No build tag on aspnet.go — OS independence comes from the `CounterSource` interface + the pdh_other.go stub.
- Fixed paths (packet step 4): no wildcard re-expansion, no `Paths()`/`RefreshInstances()` plumbing, no `changed` hook. Specs are a fixed `[]CounterSpec` built once; `NewEngine(aspnetSpecs, d.Cores)` in the factory.
- `Collect(now, dt)`: `src.Collect()` → `eng.Process(now, readings)` → map the five emitted json fields into `ASPNETGroup`; absent fields stay nil, never 0. `len(out)==0` → `nil, nil` (collector records "aspnet" in Missing).
- Machine-wide: `d.Targets` is never consulted.
- `Close()` closes the source only when the factory created it (`owned` flag), so injected fakes/shared sources are not double-closed.
- Kinds per packet: `RequestsQueued`/`RequestsCurrent`/`RequestWaitTimeMs`/`ApplicationRestarts` = `KindGauge`; `RequestsRejected` = `KindPDHRate` (engine gates it behind two valid baselines; valid-status check is the engine's, unchanged).
- No goroutine, no ticker, no text — fixed English paths + numbers only. One PDH query handle per source, reused for the source lifetime.

Note: the packet says "constant slice"; Go has no const slices, so the paths are a package-level `var aspnetPaths = []string{...}` exactly as in http.go (`httpPaths`). Specs reference `aspnetPaths[i]` so paths are defined once.
