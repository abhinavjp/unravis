## Design notes / decisions
1. **`lpc:` transport**: the driver's shared-memory dialer lives in `github.com/microsoft/go-mssqldb/sharedmemory`, which is `//go:build windows && (amd64 || 386)` and is NOT imported by the root driver package. Importing it would break the required `GOOS=linux` build and would need a third file (packet allows only two). `CheckLocalTarget` accepts all `lpc:` forms; `connDSN` drops the prefix and reaches the **same local host over TCP**. C12 (local-only) is fully preserved; only the local transport hint is lost. Documented in code.
2. **Bare `lpc:`** accepted as the local default instance (C12 lists `lpc:` as a target); DSN maps it to `.`.
3. **No `TrustServerCertificate` parameter** — the packet's DSN list does not include it, so certificate validation stays ON (encrypt=true, verify). See open question 1.
4. **`::1` DSN form**: `sqlserver://::1` (unbracketed) — verified `url.Parse` + `msdsn.Parse` accept it and the dialer's `net.ParseIP` gets a bare IPv6 (bracketed form would fail DNS in the driver). Covered by TestAppNameAndEncrypt.
5. **Error surface**: `Error{Code, Message}` with fixed sentences only; `Query` passes through an existing `*Error` and maps anything else to `query-timeout`/`query-failed`. BBX-5-07's classifier can refine `connect-failed` later without API change.
6. **Line budget**: 174 code lines (224 with comments) vs "~150" guidance — the packet requires 4 public functions + interface + config + error type + 3 test seams; comments carry the security rationale for the reviewer. No functionality beyond the packet.

## Open questions
1. **Certificate trust**: with `encrypt=true` and no `TrustServerCertificate`, a local SQL Server using the default self-signed certificate will fail the TLS handshake (`connect-failed`). The packet omits the flag, so it was not added. Reviewer decision needed for the live check: trust the local cert (still encrypted) vs require a trusted cert on the instance.
2. **`lpc:` over TCP** (note 1): acceptable, or should a later Windows-only file register the shared-memory dialer?
3. `ConnConfig.QueryTimeout` is carried for the runner (BBX-5-10) — `Open` itself does not consume it; `Query` takes the timeout per call, per packet.
