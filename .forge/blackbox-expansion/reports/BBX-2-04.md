## What was implemented
- `init()` → `RegisterGroup("sqlHost", true, newSQLHostGroup)` (optional=true).
- Counter table `sqlHostCounters` = the 13 BL-100 + BL-107 counters per instance
  prefix `<P>`; rates `KindPDHRate`, gauges `KindGauge`, LockWaitTimeMs /
  LogFlushWaitTime gauge-ms. Field setters write the matching `SQLHostInstance`
  pointer (nil when absent — missing never 0).
- `buildSQLHostTargets(prefixes)` expands the set over every discovered prefix
  into PDH paths, engine specs (Field == path, unique per instance+counter) and a
  path→(label,setter) map. Pure and cross-platform.
- `sqlInstanceLabel`: `SQLServer:` → `MSSQLSERVER`; `MSSQL$NAME:` → `NAME`.
- Factory `newSQLHostGroup(d GroupDeps)`: discover → build PDH source + engine;
  PDH error (e.g. non-Windows) returns the error so `BuildGroups` skips it.
- `Collect(now,dt)`: re-discovers ONLY when `d.ProcessSetChanged()` is true,
  otherwise reuses the one query handle; `src.Collect()` → `engine.Process` →
  fold into `[]SQLHostInstance`. Instance with no valid counter omitted; no valid
  instance → untyped nil group (not an error). Two baselines before a rate and the
  valid-status check come from the shared `Engine`.
- `discoverSQLInstances` is a package-level function variable (fakeable). Default
  `enumSQLInstancesPDH` enumerates PDH objects and keeps distinct `SQLServer:` /
  `MSSQL$…:` prefixes. `sqlEnumPDHObjects` / `sqlEnumPDHObjectsWindows` are seams.
- No SQL login/connection, no query text, no goroutine/ticker. Host PDH only.

  untagged AND only two files. `PdhEnumObjectsW`/`pdh.dll` are Windows-only
  (`golang.org/x/sys/windows` and `syscall.NewLazyDLL` both fail `GOOS=linux`

  "SQLServer MSSQL$"`, especially "Lock Wait Time (ms)" and "Log Flush Wait Time")
