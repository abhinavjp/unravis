## Implementation summary

Follows the BBX-2-01/http.go counter-group pattern exactly:

- `init() { RegisterGroup("procIO", true, newProcIOGroup) }` — optional=true.
- Factory: uses `d.Source` when injected (tests), else `NewPDHSource(procIOPaths())`; on PDH error (non-Windows) returns the error so BuildGroups skips the group. `owned` flag: `Close()` releases the handle only when the factory created the source.
- Paths (English, UNVERIFIED pending live check): `\Process(*)\ID Process` mapping + `\Process(*)\IO Read Bytes/sec`, `\Process(*)\IO Write Bytes/sec`, `\Process(*)\Page File Bytes`, `\Process(*)\Virtual Bytes`, `\Process(*)\Elapsed Time`.
- Engine specs per expanded path, key `instance + "\x00" + counter`: IO Read/Write = KindPDHRate (two-baseline gated by the existing Engine); ID Process / Page File Bytes / Virtual Bytes / Elapsed Time = KindGauge. `_Total` excluded.
- `Collect`: re-expand (`RefreshInstances` on the same handle + fresh engine) only when `d.ProcessSetChanged()` reports a change; never per tick. Folds emitted values per instance; ID Process builds instance→PID (values > 0 only). For each owner-selected target (any runtime) matches by PID, then confirms Start via Elapsed Time: `creation = now.Unix() - elapsed`, must equal `ResolvedTarget.Start` within ±3 s (`procIOStartSkew`; Elapsed Time is whole seconds sampled slightly before the tick). No instance, no PID match, missing Elapsed Time, or unconfirmed creation → target omitted. Rows sorted by Target key; no rows → `nil, nil`.
- Output `*ProcIOGroup` with `ProcIOTarget{Target: ResolvedTarget.Key, IOReadBytesPerSec, IOWriteBytesPerSec *float64; PageFileBytes, VirtualBytes *uint64; ElapsedSec *float64}`. Missing fields stay nil, never 0; negative byte gauges dropped.
- No goroutine/ticker (grep-verified), no text (fixed counter paths + numbers + owner target keys only), no attach/dump (PDH only, no process handles).

Footprint note: the packet guidance was ~150 lines; the implementation is 240 lines because it keeps the full http.go pattern (bindings, pathsOf, rebuild/refresh, owned Close) plus the required PID mapping, (PID,creation) confirmation and five-field fold. Test file is 348 lines (8 tests + fake). No drive-by refactors; nothing outside the two files changed.
