## Design notes / deviations (deliberate, behavior-preserving)
- Do-item-3 says other.go defines the ResolveTargets stub. Instead the method
  lives in the shared resolve_map.go and other.go stubs the two enumerators;
  off Windows the observable result is identical (nil + every name "not found",
  proven by TestResolveTargetsInventoryError which drives the same error path).
  This keeps the fake-driven named tests compiling AND passing under
  GOOS=linux, mirroring BBX-1-08's shared-Resolver factoring.
- `Start == 0` (creation time unreadable) → "not running", per "do not emit a
  target with PID 0 or Start 0 as if running".
- Implementation footprint: 242 lines incl. comments/blank lines (122+100+12+8)
  vs the ~150 guideline; the two Windows enumerators with safe two-call/buffer
  handling account for the bulk. Tests are 266 lines on top. No drive-by
  refactors; repo CRLF convention preserved; gofmt-clean apart from the
  repo-wide CRLF flag that affects every existing file too.
