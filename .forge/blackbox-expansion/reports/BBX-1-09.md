## What was built

`internal/blackbox/budget_bench_test.go` (package `blackbox`), fakes only — no PDH, no
process reads, no network, no real sleeps, no goroutine, no ticker:

- `fakeCounterSource` implements `CounterSource`: returns one fixed slice of 201
  readings — 200 valid (mix of `KindGauge`, `KindRate`, `KindPDHRate`, Status 0, OK
  true) plus 1 invalid (`\Memory\Pool Nonpaged Bytes`, Status 1, OK false). `Close()` nil.
- 6 fake groups (`fakeCounterGroup` implements `Group`): `http`, `iis`, `diskCpu`,
  `clr` (mandatory) + `tcp`, `memPressure` (optional). Each owns a real `Engine`
  (`NewEngine`) over its ~33-spec subset of the 201 specs and folds emitted fields
  into a small real group struct (`&HTTPGroup`, `&IISGroup`, `&DiskCPUGroup`,
  `&CLRGroup`, `&TCPGroup`, `&MemPressureGroup`). Fields the engine did not emit
  stay nil (missing never 0). The `[]Group` is constructed directly and passed to
  `NewGroupCollector` — the production registry is never touched.
- Inner host fake collector: `NewHostCollector(fakeSource, &fakeExtras{}, false)`
  reusing the `collector_test.go` fake pattern, primed once.
- Real `Budget` (`NewBudget(15)`) driven per tick exactly as the tick loop drives
  it: `Collect` → `SelfUsage` → `Cycle`. Self-usage inputs are fixed fakes under
  both limits (0.1% core, 30 MB) so the gate is deterministic: feeding measured
  wall time back would let one OS preemption flip the optional-skip and make the
  gate flaky (observed during development). The over-limit budget paths are
  covered by `budget_test.go` and by the injected slow mark below.
- `BenchmarkBudgetTick`: one full budgeted tick per iteration, `b.ReportAllocs()`,
  `now` advances 15 s per iteration.
- `TestBudgetTickStaysInTheBudget`: N=200 ticks, monotonic total / 200; FAIL if
  average > 75 ms/tick (0.5% of one core at 15 s) or > 400 allocs/tick
  (`runtime.MemStats.Mallocs` delta; measured ~87, ~4.5x headroom). Also asserts
  every tick: invalid field absent while the valid gauge beside it is present;
  after the run: no group marked slow (each group < 1 s), all six group fields
  set, and the serialized JSON line contains no `poolNonPagedBytes` key at all
  (while `poolPagedBytes` is present).
- `TestBudgetSlowGroupSkipped`: a 7th group (`vm`, mandatory) whose >1 s duration
  is INJECTED via `Budget.GroupTiming("vm", 1500ms, false)` — the only place a
  duration enters the budget — instead of a real sleep (`runGroup` times with the
  real clock, so injection is the deterministic equivalent). Asserts: marked slow
  → skipped next tick (`VM` nil, `Missing` has `skipped: slow`, 0 calls), mark
  consumed (`NoteSkipped`), re-probed the cycle after (1 call, field set). Then
  runs the 200-tick gate with the slow mark kept live so `vm` is skipped for the
  whole run: gate still passes, `vm` never runs while marked.
