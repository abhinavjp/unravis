## What was built

`internal/blackbox/clr.go` (no build tag, OS-independent), group pattern as
BBX-2-01 / http.go / diskcpu.go / sqlhost.go:

- `init() { RegisterGroup("clr", true, newCLRGroup) }` — optional=true.
- Factory `newCLRGroup(GroupDeps)`: uses `d.Source` when injected (tests), else
  `NewPDHSource(clrPaths)`; on PDH error (non-Windows / no CLR objects) returns the
  error so `BuildGroups` skips the group. Wires `d.Targets`, `d.ProcessSetChanged`,
  `d.Cores`. `owned` tracks whether the factory created the source (Close owns it).
- 10 wildcard English paths across `.NET CLR Memory(*)`, `.NET CLR LocksAndThreads(*)`,
  `.NET CLR Exceptions(*)`, including the `Process ID` mapping counter.
- Engine specs: heap sizes (Gen 0/1/2, LOH) `KindGauge` → uint64; `% Time in GC`
  `KindGauge` (uncapped); `# of current physical threads` `KindGauge`;
  `Allocated Bytes/sec`, `Contention Rate/sec`, `# of Exceps Thrown/sec` `KindPDHRate`
  (two-baseline gate). `Process ID` `KindGauge` (used only for mapping, never emitted).
- `Collect`: re-expand only on `ProcessSetChanged()` (same query handle via
  `RefreshInstances`, then rebuild specs/engine); read Process ID per instance →
  instance→PID map; for each SELECTED runtime-1 target, find its instance by PID and
  fold emitted values into a `CLRTarget` (label = `ResolvedTarget.Key`). A target with
  no CLR instance is omitted; no matched target → nil group. Missing counters stay nil.
- `Close` releases the handle only when the factory created the source.

No goroutine, no ticker, no text captured (only target keys + numbers). The instance
name (`w3wp#1`) is used internally for PID mapping and is never emitted.
