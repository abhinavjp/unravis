## What was built

`mempressure.go` copies the counter-group pattern from `internal/blackbox/http.go` /
`internal/blackbox/diskcpu.go` (BBX-2-01 / BBX-2-03):

- `func init() { RegisterGroup("memPressure", false, newMemPressureGroup) }` — **mandatory**
  (`optional=false`), same as `diskCpu`.
- Factory `newMemPressureGroup(d GroupDeps) (Group, error)`: `NewPDHSource(memPressurePaths)`
  + `NewEngine(memPressureSpecs(), d.Cores)`; **on PDH error the error is returned** so
  `BuildGroups` skips the group (non-Windows stub returns `errPDHWindowsOnly`). The
  `d.Source` seam + `owned` flag are the `http.go` pattern: an injected source is used as-is
  and is **not** closed by the group; a factory-created source is closed by `Close()`.
- `Name() = "memPressure"`, `Optional() = false`, `Close()` releases the one query handle.
- `Collect(now, _ float64)`: `src.Collect()` → `engine.Process(now, readings)` → fold into
  `*MemPressureGroup`. `len(out) == 0` → `return nil, nil` (group omitted, never zero-filled).
  A source error is returned as `(nil, err)`.
- **Machine-wide**: no `Targets` filtering, no per-process instances, no wildcard, so no
  `RefreshInstances` / `ProcessSetChanged` logic at all (fixed paths need no re-expansion).
- **Missing → nil, never 0**: a field is set only when the engine emitted its key. Byte
  gauges use the existing `v >= 0` guard before `uint64(v)` (same as `clrU64` / `proc10.go`),
  so a negative reading stays nil instead of wrapping. A **valid zero is emitted** (0 is a
  measurement, not a missing value) — asserted in `TestMemPressureMissingOmitted`.
- **Two baselines before a rate** and the **valid-status check** come from the unchanged
  engine (`KindPDHRate` gates on two valid samples; `Process` skips `!OK || Status != 0`).
- **No goroutine, no ticker, no sleep, no text**: the only strings in the file are the four
  fixed English PDH path identifiers and the group name. Output is numbers only.
- **Reused handle**: exactly one `NewPDHSource` call, in the factory; nothing is created per
  tick. The 15 s cadence is the recorder's, not the group's.
