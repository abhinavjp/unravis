## Implementation summary (the pattern for groups 2..N)
- `init()` → `RegisterGroup("http", true, newHTTPGroup)` — optional=true.
- Factory `newHTTPGroup(d GroupDeps)`: uses `d.Source` when injected (tests); otherwise `NewPDHSource(httpPaths)` and returns the error on failure so `BuildGroups` skips it (non-Windows stub returns `errPDHWindowsOnly`; also skips when HTTP.sys has no queue instances). No build tag on http.go — OS independence comes from the `CounterSource` interface + the pdh_other.go stub.
- After construction, `src.Paths()` (type-asserted `interface{ Paths() []string }`) gives the expanded paths; `parseHTTPPath` extracts the pool (text between `(` and `)`) and matches the counter suffix. Per-(pool,counter) `CounterSpec`s are built with `Field = pool + "\x00" + jsonField` (NUL cannot occur in a PDH instance name, so keys are unambiguous) and a fresh `NewEngine(specs, d.Cores)`. An aligned `[]httpCounter{key,pool,field}` maps engine output back to `HTTPQueue` fields — no string parsing in the hot path.
- Kinds per packet: `CurrentQueueSize`/`MaxQueueItemAge` = `KindGauge`; `RejectedRequests`/`ArrivalRate` = `KindPDHRate` (engine gates both behind two valid baselines; valid-status check is the engine's).
- `Collect(now, dt)`: re-expand ONLY when `g.changed != nil && g.changed()` (`d.ProcessSetChanged`), via type-asserted `RefreshInstances()` on the same source/query handle, then rebuild specs/engine from `Paths()`. Then `src.Collect()` → `engine.Process(now, readings)` → group emitted fields by pool into `[]HTTPQueue`, sorted by pool name for deterministic output. A pool with no valid field is omitted (queues are created only on an emitted field); missing fields stay nil, never 0. `len(out)==0` → `nil, nil` (collector records the name in Missing).
- Machine-wide: `d.Targets` is never consulted; all expanded queues are emitted (proven by TestHTTPGroupMapsPools with Targets listing only one of two pools).
- `Close()` closes the source only when the factory created it (`owned` flag), so injected fakes/shared sources are not double-closed; `groupCollector.Close` picks it up via `io.Closer`.
- No goroutine, no ticker, no request text/URLs — pool names + numbers only. One PDH query handle per source, reused for the source lifetime (PDHSource contract).
