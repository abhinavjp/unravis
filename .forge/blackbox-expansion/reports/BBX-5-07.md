## Implementation notes / deliberate decisions

1. **Error type reuse (packet deviation, forced):** the packet sketches `type Error struct { Code string }` in errors.go, but BBX-5-06 already defines `Error{Code, Message}` in conn.go (outside this packet's file scope). errors.go reuses that type — same semantics (fixed Code + fixed Message, never driver text). No redefinition, no conn.go edit.
2. **Truncation-safe ceiling perms query (security-critical deviation from the example SQL):** `statementCap` (output.go, out of scope) defaults unknown statements to cap 1, so `DBQueryer`/`Query` read at most 2 rows. A plain `SELECT permission_name ...` full list could therefore hide an extra right beyond row 2 — NOT fail-closed. Fix within scope: `bb:ceiling_perms` keeps the packet's shape but adds `AND permission_name NOT IN (N'CONNECT SQL', N'VIEW ANY DATABASE', N'VIEW SERVER STATE', N'VIEW SERVER PERFORMANCE STATE')` plus `TOP 2`, so it returns ONLY rights outside the ceiling. Any returned row ⇒ refusal; zero rows ⇒ provably within ceiling (truncation can only remove rows, never fabricate an empty result). The Go subset assert (`ceilingAllowed`) still runs on every returned row as the second gate, exactly as the packet requires. `TestCeilingQueriesLintClean` pins this design.
3. **Role query** is the packet's example verbatim (N-prefixed literals, package style): `SELECT IS_SRVROLEMEMBER(N'sysadmin') AS sysadmin, IS_SRVROLEMEMBER(N'securityadmin') AS securityadmin`. Go asserts both flags == 0; NULL/non-numeric ⇒ fail-closed `failed` ("The login rights check could not be completed."), never treated as 0.
4. **Refusal message** is exactly the packet's plain reason: `this login has more rights than the Blackbox needs` (code `too-many-rights`), exported as `ErrTooManyRights`.
5. **Classify** is written fresh (not copied from dbhealth): mssql.Error numbers first (18456/18452/18451/18488/18487 login; 4060/911 database; 229/230/262/297/916/15151/15247 permission; -2 timeout), then `context.DeadlineExceeded`, then stable lowercase phrases, fallback `failed`. Already-fixed `*Error` values pass through unchanged (so `ErrTooManyRights` keeps its code). `CodeConnectTimeout = "timeout"` is distinct from conn.go's `CodeTimeout = "query-timeout"` (C4 query budget).
6. **Lint extensions** (allowlist_test.go): requiredIDs now pins nine ids; `TestLintTOPCaps` pins `SELECT TOP 2 ` for bb:ceiling_perms; `outputColumns` handles a FROM-less SELECT by cutting the column list at the tag comment (needed for bb:ceiling_role; `TestNoBannedTokenInOutput` now covers its `sysadmin`/`securityadmin` output columns — both clean).
