## Design notes / decisions

- Extra fields in status.json reject the ENTIRE file (→ off), the stricter of the packet's "rejected/ignored" options; matches `parseDraft` precedent.
- Bad state normalizes only `State` to "off" (packet whitelists state only); `Enabled`/`Failures` keep their decoded values when the file is otherwise valid.
- `dec.More()` refuses trailing text after the closing brace, same strictness as config parsing.
- Path uses the existing `SQLDataDir(folder)` helper (BBX-5-01) rather than re-joining "sql" manually.
