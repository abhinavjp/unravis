## Design
- `init() { RegisterGroup("dumps", true, newDumpsGroup) }` — optional, OS-independent
  (no build tags), factory always succeeds; on non-Windows the fixed roots do not
  exist, the walk skips them and Collect returns nil (group omitted).
- `catalogueDumps(roots []string) []DumpEntry` mirrors `CatalogueLogs` (logs.go):
  `filepath.WalkDir`, depth cap by separator count from the root, visited cap with
  `fs.SkipAll`, symlink skip, case-insensitive `*.dmp`, **only `d.Info()`** (stat),
  `Name = d.Name()` (base name only), `MTime` UTC truncated to seconds, newest-first
  sort (tie-break by name), cap 200.
- Caps: `dumpMaxDepth = 2`, `dumpMaxVisited = 500`, `dumpMaxListed = 200`.
- Fixed roots (`dumpRoots()`): `C:\Windows\Minidump`, `%LOCALAPPDATA%\CrashDumps`,
  `%ProgramData%\Microsoft\Windows\WER\ReportArchive` and `...\ReportQueue`
  (env vars via `os.Getenv` + `filepath.Join`; unset env → root omitted).
- Cadence: `dumpsEvery = 5 * time.Minute`; Collect re-scans only when
  `lastScan.IsZero() || now.Sub(lastScan) >= dumpsEvery || now.Before(lastScan)`
  (same shape as recorder.go:225 logs cache), else returns the cached result.
  Last scan time + result cached on the group. No goroutine, no ticker.
- `dumpTarget`: `w3wp.exe.1234.dmp` → `w3wp`, `iexplore.exe_5678.dmp` → `iexplore`,
  `svchost.exe.dmp` → `svchost`; requires a `.`/`_`/end boundary after `.exe`
  (case-insensitive), else `""`. Never a path, never content.
- Empty/missing roots → `nil, nil` from Collect (never a 0-entry group).

Note: the packet sketched `catalogueDumps(roots []string, now)`; implemented as
`catalogueDumps(roots []string)` — `now` is unused by a stat-only catalogue (the
clock belongs to Collect's cadence). Roots stay injectable; tests use temp dirs.
