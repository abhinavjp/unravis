Ranked risks — IIS timestamp semantics is #1.

  1. 1 IIS timestamp semantics unverified
    Label approximate; test owner files
  2. 2 Tracing vs Run analysis diverge
    Same analyze query on click-through
  3. 3 50k cap hides spikes
    Show truncated + narrow window
  4. 4 No live SQL in MVP
    Imports-only copy
  5. 5 TZ skew not auto-fixed
    Disable until rules validated
  6. 6 Wireframe scope creep
    Later backlog + MVP sign-off
  7. 7 Call trace expectations
    Do not advertise unwired UI
  8. 8 7-day performance
    Coarsen buckets + timeout
