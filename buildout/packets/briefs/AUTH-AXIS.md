# Spec for packet AXIS (id axis)
Goal: charts show axis numbers with units, and an incident marker. Files: `parts/11-charts-*.js` (chart renderers), `parts/12-evidence-a.js`, `12-evidence-b.js`, `12-evidence-c.js` (evidence chart builders; a card's chart definition includes a unit field, find with grep `unit`). Every line, stacked-area and bar chart gets: a y axis with 3 tick labels (0, mid, max, formatted compactly with the unit, e.g. `1.2k ms`), an x axis with first/middle/last time labels where the chart has times, and a vertical dashed incident-window marker on time-based charts (stacked and bar included) using the fixture's incident indexes if present, else omitted. Text uses class `axis-label`. Do not change chart output for charts with no data. Split into the smallest packets that touch one file each if the work is bigger than ~10 KB of diff; output ONE packet per file group with ids AXIS-1, AXIS-2.. and one check each. Check script: assert tick labels and unit appear for each chart kind with the real fixtures (`EVIDENCE` data in parts 13-14).
